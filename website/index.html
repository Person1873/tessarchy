TESTER RELEASE

A place to start.

The published Alpha 1 ISO has been observed booting into Tessera in BIOS and UEFI QEMU/KVM. It predates the Quiet Edge and card-switcher changes shown here.

A live x86_64 environment, with no disk installer or persistent storage. A physical keyboard is required.
